XML Markup

Everything the Java builder API can do also has an HTML-like markup form, parsed by dev.htmlib.markup.MarkupLoader.

Menu menu = MarkupLoader.parse(markupString);
Menu menu = MarkupLoader.parseFile(Path.of("menus/shop.xml"));

Both accept an optional ConditionRegistry as a second argument if you've registered custom condition prefixes (see Conditions) — otherwise a fresh default registry is used.

Under the hood: markup is parsed as real XML (DOCTYPE declarations and external entities are disabled), so it must be well-formed — close every tag, quote every attribute.

<menu> — the root element

Every document must have exactly one root <menu> element.

AttributeDefaultEffect
idauto-generatedThe menu's registry id.
title(empty)Menu title.
close-on-escapetrueSet to "false" to disable.
typedialog"dialog" or "inventory".
rows—Inventory row count, 1–6 (also forces type="inventory").
submit-action—Action id for the auto-added submit button.
submit-label"Submit"Label for the submit button.

Child elements

TagMaps to
<div>Div — plain container
<row>Row — horizontal flex container
<column>Column — vertical flex container
<list>ListComponent — container; wire up its data source/renderer in Java after parsing
<button>Button
<text>Text
<icon>Icon
<image>Image
<input>Input
<style>not a component — a CSS-like block, see below

<div>, <row>, <column> and <list> can nest any of the elements above, including each other.

Attributes available on every element

AttributeEffect
idElement id.
classSpace-separated CSS class names, matched against <style> rules.
visible-ifA condition expression gating visibility.
permissionShorthand for visible-if="permission:<node>".
styleInline declarations, e.g. style="gap:2;align:center".
gap, align, direction, orderShorthands that each set the matching style property directly.

<button>

The element's text content becomes the button label (whitespace is collapsed).

AttributeEffect
iconItem material id.
tooltipHover tooltip.
actionAction id fired on click. "back", "close" and "open:<menuId>" are handled automatically.
widthButton width (dialog rendering).
enabled-ifCondition expression — disables (rather than hides) the button.
<button icon="diamond_sword" tooltip="50 coins" action="myplugin:buy.sword">
    Buy Sword
</button>

<text>

Element text content becomes the text content, with {{ variable }} tokens interpolated at render time.

<text>Welcome, {{ player.name }}!</text>

<icon>

AttributeEffect
materialItem material id. Falls back to the element's text content if omitted.
countStack size.
show-tooltip"true"/"false".
<icon material="emerald" count="3" />

<image>

AttributeEffect
src (or source)Image source.
fallback-iconMaterial used to represent the image (see the note in Components → Image).

<input>

Requires a key (or id) attribute.

AttributeEffect
key / idRequired. The key values are read back under.
labelField label.
typetext (default), boolean/bool, number/number-range, or option/single-option.
initialInitial value — text string, "true"/"false", or a number, depending on type.
min, max, stepnumber type only.
optionsoption type only — comma-separated list, e.g. options="small, medium, large".
widthField width.
<input key="amount" type="number" label="Amount" min="1" max="64" initial="1" />
<input key="size" type="option" label="Size" options="small, medium, large" />

<style>

A CSS-like block of class-based rules. Rules only fill in style properties an element doesn't already have set inline — inline style/shorthand attributes always win.

<style>
    .highlight { gap: 3; align: center; }
    .danger, .warn { direction: horizontal; }
</style>

<row class="highlight">
    ...
</row>

Full example

<menu id="myplugin:shop" title="Shop" submit-action="myplugin:shop.checkout">
    <style>
        .row-gap { gap: 3; }
    </style>

    <text>Welcome, {{ player.name }}! You have {{ shop.coins }} coins.</text>

    <row class="row-gap">
        <button icon="diamond_sword" tooltip="50 coins" action="myplugin:buy.sword">
            Buy Sword
        </button>
        <button icon="shield" tooltip="80 coins"
                action="myplugin:buy.shield" enabled-if="permission:myplugin.shop.shield">
            Buy Shield
        </button>
    </row>

    <input key="quantity" type="number" label="Quantity" min="1" max="10" initial="1" />

    <row>
        <button icon="barrier" action="close">Close</button>
    </row>
</menu>

{{ shop.coins }} here is a stand-in for a variable your own plugin would register — see Variables.
