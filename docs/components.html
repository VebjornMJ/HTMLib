Components

Every menu is a tree of Component objects, built with a fluent Java API. All of these live in dev.htmlib.api.component.

Component — shared by everything

Every component (including containers) extends the abstract Component<SELF> and inherits these methods, all of which return this for chaining:

MethodEffect
id(String)Sets an element id, mainly useful for markup / debugging (toString() includes it).
cssClass(String... classes)Adds one or more CSS-style class names, used by <style> rules in markup.
style(String key, String value)Sets a single inline style declaration.
visibleIf(Condition)Hides this element (and, for containers, everything inside it) when the condition is false.
permission(String node)Shorthand for visibleIf(Condition.permission(node)).

See Variables & Conditions for how Condition works.

Container — anything that can hold children

Container<SELF> extends Component and adds child-management. It's the base of Menu, Div, Row, Column and ListComponent:

MethodEffect
add(Component<?>... components)Appends one or more children directly.
text(String content)Shorthand for add(new Text(content)).
button(String text)Creates and adds a Button, returning a ButtonBuilder for further chaining.
row(Consumer<Row>)Creates, adds and configures a nested Row.
column(Consumer<Column>)Creates, adds and configures a nested Column.
div(Consumer<Div>)Creates, adds and configures a nested Div.

ButtonBuilder

container.button("text") returns a ButtonBuilder so you can configure the button and keep chaining on the parent container:

row.button("Buy Sword")
      .icon("diamond_sword")
      .tooltip("50 coins")
      .action("myplugin:buy.sword")
      .enabledIf(hasEnoughCoins)
   .button("Close").icon("barrier").action("close");

Call .and() to get back the parent container explicitly, or .build() to get the underlying Button.

Menu

The root of every UI tree. Created with the static factory Menu.create(String menuId) — there's no public constructor.

MethodEffect
title(String)Menu title.
canCloseWithEscape(boolean)Whether pressing Escape closes the menu (dialog rendering only). Default true.
submitAction(String) / submitLabel(String)Adds an extra submit button that fires this action id with every <input> value attached. See Inputs & submit.
dialog() / inventory()Selects the render type. Default is dialog().
inventoryRows(int)Selects inventory rendering with 1–6 rows (clamped).
show(Player)Opens this menu for a player immediately.

Row & Column

Flex-style layout containers. Both default to display: flex with a gap of 1; Row lays children out horizontally, Column vertically.

menu.row(row -> row.gap(2).align("center")
    .button("A")
    .button("B"));
MethodEffect
gap(int)Sets the gap style property.
align(String)Sets the align style property.

Div

A plain grouping container with no layout defaults of its own — use it when you just need to group elements (for a shared visibleIf, a shared CSS class, etc.) without Row/Column's flex defaults.

Button

MethodEffect
text(String)Label shown on the button.
icon(String)Item material id shown next to/on the button, e.g. "diamond_sword".
tooltip(String)Hover tooltip text.
action(String)The action id dispatched when clicked. See Actions & Events.
width(int)Button width in dialog rendering (clamped to 1–1024).
enabledIf(Condition)Keeps the button visible but rejects clicks when false, instead of hiding it like visibleIf would.

Text

Static text content. Supports {{ variable }} interpolation, resolved fresh every time the menu is rendered.

new Text("Welcome, {{ player.name }}!")
container.text("Online: {{ server.online }}");

Icon

MethodEffect
material(String)Minecraft item id, e.g. "diamond_sword" or "minecraft:diamond_sword". Unresolvable materials fall back to stone.
count(int)Stack size shown on the icon (minimum 1).
showTooltip(boolean)Whether hovering shows the item's tooltip. Default true.

Image

MethodEffect
source(String)Image source.
fallbackIcon(String)Material used to represent the image. Default "minecraft:painting".
Note: in the current renderer, an Image element is always drawn using its fallbackIcon material — set that to whatever best represents the image you want to show.

Input

A form field, submitted as part of a menu's submitAction (or read directly off any button click). Created with new Input(String key) — the key is how you'll read the value back from ActionEvent.

The input's type is inferred by which setter you call:

MethodSets typeEffect
initialText(String)TEXTFree text field, default type.
initialBoolean(boolean)BOOLEANCheckbox / toggle.
numberRange(min, max, step, initial)NUMBERBounded numeric slider.
options(String...)OPTIONSingle-choice picker over the given options.

Plus, on every type: label(String) and width(int) (default 200).

ListComponent<T>

A container that renders one child per item from a data source — useful for player-specific lists (inventories, shop stock, friend lists, etc.).

MethodEffect
dataSource(Function<Player, List<T>>)Supplies the items to render for a given player.
itemRenderer(Function<T, Component<?>>)Converts each item into the component shown for it.
new ListComponent<ShopItem>()
    .dataSource(player -> shop.stockFor(player))
    .itemRenderer(item -> new Button()
        .text(item.name())
        .icon(item.material())
        .action("shop:buy:" + item.id()));
