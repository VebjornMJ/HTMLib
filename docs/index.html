HTMLib

Build modern Minecraft server UI, HTML/CSS-style — then render it as either Mojang's native dialog UI or a classic chest inventory GUI, your choice per menu.

HTMLib is a Paper plugin that lets you describe a menu once — as a fluent Java builder chain or as HTML-like XML markup — and show it to a player without caring which underlying Minecraft UI system renders it. The same <button>, <text> and <input> elements work whether the menu ends up as a native dialog or a chest GUI.

Requirements

ServerPaper, API version 26.2 or newer
OptionalPlaceholderAPI 2.11+ (soft dependency — enables %placeholder% tokens automatically)

Installation

  1. Build or download htmlib-paper-<version>.jar. This single jar already bundles HTMLib's api, layout, events, navigation and markup modules — nothing else to install.
  2. Drop it into your server's plugins/ folder.
  3. Restart (or /reload) the server.
  4. Run /htmlib list to confirm it loaded — you should see the built-in htmlib:demo menu registered.
Try it now: as a player, run /htmlib demo to open the built-in demo menu and see dialog rendering in action.

Quick start

Every menu is a Menu component tree. Build one in Java with the fluent builder API, register it, and open it for a player:

Menu menu = Menu.create("myplugin:shop")
    .title("Shop")
    .text("Welcome, {{ player.name }}!")
    .row(row -> row
        .button("Buy Sword").icon("diamond_sword").tooltip("50 coins")
            .action("myplugin:buy.sword")
        .button("Close").icon("barrier").action("close")
    );

HTMLib.menus().register(menu);
HTMLib.registerAction("myplugin:buy.sword", event ->
    event.player().sendMessage("You bought a sword!"));

// later, e.g. from a command
menu.show(player);

Or describe the same menu as markup and load it with MarkupLoader:

Menu menu = MarkupLoader.parse("""
    <menu id="myplugin:shop" title="Shop">
        <text>Welcome, {{ player.name }}!</text>
        <row>
            <button icon="diamond_sword" tooltip="50 coins" action="myplugin:buy.sword">
                Buy Sword
            </button>
            <button icon="barrier" action="close">Close</button>
        </row>
    </menu>
    """);

Admin command

HTMLib ships a small admin/diagnostics command, guarded by the htmlib.admin permission (default: op):

CommandDescription
/htmlib listLists every currently registered menu id.
/htmlib open <menu> [player]Opens a registered menu for yourself, or for another online player.
/htmlib demoOpens the built-in demo menu for yourself.
