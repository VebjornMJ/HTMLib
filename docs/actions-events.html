Actions & Events

Actions are how a button click reaches your plugin's code. Events are a lightweight publish/subscribe bus for menu lifecycle notifications.

Actions

Every Button (and a menu's submitAction) carries an action id. When it's clicked, HTMLib dispatches an ActionEvent through the ActionRegistry.

Built-in navigation actions

These three ids are handled automatically — you never need to register them:

Action idEffect
backReturns to the previous menu in the player's history.
closeCloses the current menu.
open:<menuId>Opens another registered menu by id.
<button icon="barrier" action="close">Close</button>
<button icon="chest" action="open:myplugin:shop">Open Shop</button>

Registering a custom action

HTMLib.registerAction("myplugin:buy.sword", event -> {
    Player player = event.player();
    if (economy.withdraw(player, 50)) {
        player.getInventory().addItem(new ItemStack(Material.DIAMOND_SWORD));
        player.sendMessage("Purchased!");
    } else {
        player.sendMessage("Not enough coins.");
    }
});

Action is a @FunctionalInterface: void handle(ActionEvent event). HTMLib.registerAction(id, action) is shorthand for HTMLib.actions().register(id, action); use HTMLib.actions().unregister(id) to remove one.

ActionEvent

MethodReturns
player()The Player who clicked.
actionId()The action id that fired.
menu()The Menu that was open when it fired.
source()The Button that fired it, or null for a menu-level submit action.
inputs()Map<String, Object> of submitted <input> values, keyed by input key.
inputText(key) / inputBoolean(key) / inputNumber(key)Typed convenience getters over inputs(), returning null if absent or the wrong type.
open(String menuId) / open(Menu)Navigate to another menu from inside a handler.
back() / close()Same navigation the built-in actions perform.
HTMLib.registerAction("myplugin:shop.checkout", event -> {
    Integer quantity = event.inputNumber("quantity") != null
        ? event.inputNumber("quantity").intValue() : 1;
    // ... process purchase ...
    event.close();
});

Menus must be registered to be opened by id

action="open:<id>", HTMLib.open(player, "id") and /htmlib open all look the menu up in the MenuRegistry. Register it once, typically in your plugin's onEnable:

HTMLib.menus().register(menu);

Opening a Menu object directly — menu.show(player) or HTMLib.open(player, menu) — doesn't require registration.

Events

HTMLib publishes a small set of lifecycle events through its own EventBus — independent of Bukkit's event system, so you subscribe through HTMLib.events() rather than @EventHandler:

HTMLib.events().subscribe(MenuOpenEvent.class, event ->
    getLogger().info(event.player().getName() + " opened " + event.menu().menuId()));
EventFieldsPublished when
MenuOpenEventPlayer player, Menu menuA menu is shown to a player (including the first menu in a navigation chain).
MenuBackEventPlayer player, Menu menuA player navigates back to a previous menu.
MenuCloseEventPlayer player, Menu menuA menu is closed (including via the close action).
ActionInvokedEventActionEvent source, boolean handledAfter every action dispatch attempt — handled tells you whether anything actually processed it.
